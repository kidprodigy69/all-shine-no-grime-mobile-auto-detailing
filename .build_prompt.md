10. GSAP + REACT LIFECYCLE RULE — CRITICAL, NO EXCEPTIONS:
    Any component that uses GSAP ScrollTrigger (especially with `pin: true`) MUST use
    `useLayoutEffect` instead of `useEffect`. And the cleanup MUST explicitly kill
    ScrollTriggers BEFORE reverting the context:

    CORRECT:
      useLayoutEffect(() => {
        const ctx = gsap.context(() => { ... }, containerRef)
        return () => {
          ScrollTrigger.getAll().forEach(st => st.kill())
          ctx.revert()
        }
      }, [])

    WRONG (causes "removeChild" crash on navigation):
      useEffect(() => {
        const ctx = gsap.context(() => { ... }, containerRef)
        return () => ctx.revert()  // async — fires after React removes DOM
      }, [])

    WHY: `pin: true` moves DOM nodes to a GSAP proxy wrapper. `useEffect` cleanup is
    async (fires after paint). By the time it runs during React navigation, React has
    already removed the original DOM node from its parent — triggering the crash.
    `useLayoutEffect` fires synchronously before the browser paints, giving GSAP time
    to unpin and restore the DOM before React's reconciler touches it.

## FRAMER MOTION — MANDATORY ON EVERY PAGE

Hero:     ANIMATED TEXT (word or character stagger) — not a simple fade. See patterns below.
Sections: scroll-triggered via whileInView, once: true, margin: "-100px"
Cards:    stagger 50–100ms between siblings via variants
Buttons:  whileHover scale + color transition
Images:   hover zoom or clip-path reveal

Standard scroll reveal:
  initial={ opacity: 0, y: 30 }
  whileInView={ opacity: 1, y: 0 }
  transition={ duration: 0.6 }
  viewport={ once: true, margin: "-100px" }

### REQUIRED: ANIMATED TEXT PATTERNS (use at least 2 per build)

**Pattern A — Word stagger (most impactful):**
Split the hero headline into words. Each word slides up with a staggered delay.
```tsx
const words = headline.split(' ')
<motion.h1>
  {words.map((word, i) => (
    <motion.span key={i} style={{display:'inline-block', marginRight:'0.25em'}}
      initial={{ opacity: 0, y: 60 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ delay: i * 0.08, duration: 0.6, ease: [0.16, 1, 0.3, 1] }}>
      {word}
    </motion.span>
  ))}
</motion.h1>
```

**Pattern B — Clip-path line reveal:**
```tsx
<motion.div style={{overflow:'hidden'}}>
  <motion.p
    initial={{ clipPath: 'inset(0 100% 0 0)' }}
    whileInView={{ clipPath: 'inset(0 0% 0 0)' }}
    transition={{ duration: 0.9, ease: [0.16, 1, 0.3, 1] }}>
    {text}
  </motion.p>
</motion.div>
```

**Pattern C — Character stagger (for short punchy headlines):**
```tsx
{headline.split('').map((char, i) => (
  <motion.span key={i}
    initial={{ opacity: 0, rotateX: -90 }}
    animate={{ opacity: 1, rotateX: 0 }}
    transition={{ delay: i * 0.03, duration: 0.4 }}>
    {char === ' ' ? ' ' : char}
  </motion.span>
))}
```

Use Pattern A or B on the hero headline. Use Pattern C on section subheadings or CTAs.
Section headlines (h2) must use at least a word stagger or clip-path reveal — not a plain fade.
